# Expand the dock Documentation label

## Why

The horizontal dock now shows Canvas Components in full; Documentation is
clearer and more consistent beside it than Docs.

## What changes

Use Documentation for the dock item label and accessible name (and its
vertical tooltip). Preserve the book icon and /docs-landing destination.
Allow multiword mobile labels to wrap to two lines with aligned icons, so the
longer Documentation label does not clip Canvas Components at 390px. Preserve
the existing scrollable navigation strip for smaller screens. No dependencies change.
