# Canvas Components naming

## Why

Use the requested expanded name and a diagram-like icon so the canvas
showcase is easier to recognize than the CBUN abbreviation.

## What changes

- Name the page, home feature tile, and navigation/search entry Canvas Components Bundle.
- Use the tree-structure icon for that title, feature tile, and dock item.
- Use Canvas Components for the dock label, accessible name, and tooltip.
- Keep the /cbun route and its CBUN search keyword; refresh search content.

No dependency changes.
